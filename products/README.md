# Derived Products

Each product is built from a named release of the core document. Every product
has a brief before it is assembled and a manifest that names the core release
and source files it uses. Substantive improvements discovered while building a
product go back into `content/` first.

| Product | Purpose |
|---|---|
| [web-guide/](web-guide/brief.yml) | The published Topic Reference on GitHub Pages, with on-page comments |
| [infographic/](infographic/brief.yml) | The primary infographic, the topic at a glance, built from [content/infographic.yml](../content/infographic.yml) with the core document |
| [presentation/](presentation/brief.yml) | A review deck built with the shared PowerPoint template |
